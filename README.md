# SQL Queries

This section contains the SQL queries used to analyse ZoomRide's ride-hailing data, identify data quality issues, clean the dataset, and generate business insights using MySQL.

## Q1. Total Number of Trips

Count the total number of records in the trips table.

```sql
SELECT COUNT(*) AS Number_of_Rows
FROM trips;
```

## Q2. Five Longest Completed Trips

Retrieve the five longest completed trips, ordered by distance from highest to lowest.

```sql
SELECT
    trip_id,
    city,
    distance_km,
    fare
FROM trips
WHERE status = 'Completed'
ORDER BY distance_km DESC
LIMIT 5;
```

## Q3. Total Number of Trips in Each City

Count the number of trips recorded for each city.

```sql
SELECT
    city,
    COUNT(*) AS total_trips
FROM trips
GROUP BY city;
```

**Data quality observations:**

* Inconsistent city names resulted in separate entries for cities such as Lagos, Kampala, and Port Harcourt.
* Spelling and naming inconsistencies included `Port-Harcourt`, `PH`, `Kampla`, and `Nairobbi`.
* Leading and trailing whitespace affected city names such as Lagos and Accra.

## Q4a. Identifying Duplicate Trips

Identify potential duplicate trips using customer ID, driver ID, trip date, and fare. The minimum and maximum trip IDs help identify the records involved.

```sql
SELECT
    customer_id,
    driver_id,
    trip_date,
    fare,
    MIN(trip_id) AS first_trip_id,
    MAX(trip_id) AS later_trip_id
FROM trips
GROUP BY
    customer_id,
    driver_id,
    trip_date,
    fare
HAVING COUNT(*) > 1;
```

## Q4b. Completed Trips with Missing Fares

Identify completed trips where the fare value is missing.

```sql
SELECT
    trip_id,
    status,
    fare
FROM trips
WHERE status = 'Completed'
  AND fare IS NULL;
```

## Q5. Data Cleaning

Standardise inconsistent city names, remove leading and trailing whitespace, and delete the identified duplicate records.

```sql
UPDATE trips
SET city = 'Nairobi'
WHERE city = 'Nairobbi';

UPDATE trips
SET city = 'Kampala'
WHERE city = 'Kampla';

UPDATE trips
SET city = 'Port Harcourt'
WHERE city IN ('PH', 'Port-Harcourt');

UPDATE trips
SET city = TRIM(city);

DELETE FROM trips
WHERE trip_id IN (299, 300);
```

## Q6. Revenue by City

Calculate the number of completed trips, revenue, and average fare for each city. Results are ordered by revenue from highest to lowest.

```sql
SELECT
    city,
    COUNT(*) AS number_of_trips,
    SUM(fare) AS revenue,
    ROUND(AVG(fare), 2) AS average_fare
FROM trips
WHERE status = 'Completed'
GROUP BY city
ORDER BY revenue DESC;
```

## Q7. Revenue by Month

Analyse monthly completed trips and recorded revenue in chronological order.

```sql
SELECT
    DATE_FORMAT(trip_date, '%Y-%m') AS month,
    COUNT(*) AS number_of_trips,
    SUM(fare) AS revenue
FROM trips
WHERE status = 'Completed'
GROUP BY month
ORDER BY month ASC;
```

**Key finding:** December 2025 was the best month by recorded revenue, with 31 completed trips generating ₦66,980.

## Q8. Revenue by Vehicle Type

Join the trips and drivers tables to compare completed trips and recorded revenue across vehicle types.

```sql
SELECT
    d.vehicle_type,
    COUNT(*) AS number_of_trips,
    SUM(t.fare) AS revenue
FROM trips t
INNER JOIN drivers d
    ON t.driver_id = d.driver_id
WHERE t.status = 'Completed'
GROUP BY d.vehicle_type
ORDER BY revenue DESC;
```

## Q9. Customers Who Have Never Booked a Trip

Use a `LEFT JOIN` to identify customers without any matching trip records.

```sql
SELECT
    a.customer_id,
    a.customer_name
FROM customers a
LEFT JOIN trips b
    ON b.customer_id = a.customer_id
WHERE b.customer_id IS NULL;
```

## Q10. Top Three Customers by Total Spend

Join customers to trips, calculate total spend per customer, and return the three highest spenders.

```sql
SELECT
    a.customer_name,
    SUM(b.fare) AS total_spend
FROM trips b
INNER JOIN customers a
    ON b.customer_id = a.customer_id
GROUP BY
    a.customer_id,
    a.customer_name
ORDER BY total_spend DESC
LIMIT 3;
```
